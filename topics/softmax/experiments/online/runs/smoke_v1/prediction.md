# 下一轮 online pilot：事前预测与范围草案

记录日期：2026-09-05。归属与先后顺序明确如下：已知 scratch 与审计反例是事后背景；
本记录在新的随机扫描之前写入。它是扩展 pilot 的预测记录，不是确认实验预注册。
本轮只运行已有确定性算例来验收 runner；随机范围配置尚未运行。

## 用户预测（原话）

在被问到“固定 spread 时，块数增大后 chain 相对 balanced 的误差差距，预计会扩大、
基本不变，还是没有稳定方向”后，用户回答：**“没有稳定方向吧”**。

这是对块数趋势的定性预测，不自动等于“两种 schedule 的平均误差相同”，也不是
对每个输入必然反转的断言。数值量级、何谓稳定及 FMA 的方向尚未由用户指定。
下述分析建议由 agent 提供，不能倒写成用户的独立推导。

## Agent 预测草稿（与用户预测分开）

- **Direction**：个体配对差允许变号；我的弱预测是较大块数下 chain 的平均劣势更容易
  出现，但不预测逐族、逐格单调。FMA 会改变个别输入的结果，不预设它改善最终误差。
- **Scale**：先按约 $10^{-8}$ 到 $10^{-6}$ 的相对误差量级观察；这来自已见 scratch，
  不是新证据、检测阈值或误差上下界。树深度的最坏情形界不能直接充当平均增长率。
- **Boundary**：最大值位置、spread、误差抵消以及接近精确可表示分母的输入都可能
  破坏简单趋势。32 块保留；不把 balanced 的小误差称为正的测量地板。
- **Failure signature**：如果较大块数的同 spread 配对差仍频繁反转、均值无一致变化，
  需要削弱我的增长预测。反过来，跨 spread/舍入模式的一致趋势会挑战用户的定性预测；
  小样本不能据此确认或否定总体命题。重放失败、同族输入不一致属于工程错误，先停查。

## 扩展 pilot 配置草案

- 常值块，每块 32 个元素，块内初始化精确。
- uniform spread：8、25；块数：32、128、512、2048；每格 8 个显式种子。
  共 64 个随机族。各格种子不重复，块数之间不是同一随机序列的前缀配对。
- chain 与 balanced；两种 FMA arm 对同一族共同运行。exp 固定为当前默认的
  correctly-rounded FP32 exp。这轮不声称比较不同 exp 实现。
- 主要记录 $D=A_{chain}-A_{balanced}$，正数表示 chain 更差。每个族保存严格数值区间；
  分 spread、块数与 FMA arm 展示，不能先跨格混池。FMA 配对可从同族两 arm 结果再分析。
- runner 当前输出逐族记录及配对差，不提供统计 CI。后续汇总实现仍需独立验证，
  样本量规划、稳定趋势的操作定义和确认阈值尚未冻结；8 个族用于探索，不用于确认。
- 执行时间未知，先依据确定性 smoke 的工程耗时规划批次；不得依据新随机测量的
  正负方向决定补跑哪个格或删掉哪个格。若调整草案，保留版本与原因。

配置在 [expansion_v1.json](../experiments/online/plans/expansion_v1.json)。
在固定下一轮问题、汇总口径和资源预算后再运行；结果必须进入新目录。
