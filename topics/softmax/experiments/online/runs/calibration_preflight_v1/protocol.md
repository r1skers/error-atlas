# Online 统计方法校准设计 v1（尚未运行 Monte Carlo）

2026-09-06。本阶段只用已知真均值的合成 D 分布检查推断方法，不生成 softmax 确认输入。
数值工具与统计方法的正确性分开；合成分布上的覆盖表现不能保证所有输入分布的覆盖。
确认范围和样本量仍见[确认轮草案](online_confirmation_draft_v1.md)。

## 运行前预测

用户在本轮 Monte Carlo 运行前回答：**“后者问题大一点？不太清楚”**。
问题对比“真均值为零的正负对称分布”和“多数小正值、偶尔大负值的零均值分布”。
这是带不确定性的方向预测，不补充用户未给出的量级。

Agent 预测：稀有负尾分布更可能使 percentile 正均值判据误报；若样本未观察到负尾，
重抽本批数据不会生成未观察到的尾部。正尾反射与正负对称条件用作方向对照。
常零总体应覆盖真值且不拒绝零；常正总体用于检验“拒绝零”不等于“误报”。
以上是事前机制判断，不是校准结果。

## 外层与内层

外层一次实验：从已知总体独立抽 n 个联合族，每族有 separate/FMA 两项 D。
内层：在同批族上生成 B 个共用索引的 bootstrap 重采样，得到两个均值分布。
换一个外层实验时重新抽全部 n 个族。误报率与覆盖率在外层实验之间统计，
不能把同一批数据的 B 次重采样当作 B 次覆盖试验。

候选一是 percentile 单侧下界，alpha=1/20，沿用用户的 (B−1)p 线性插值。
数值外包为 [q_low,q_high] 时实际使用 L=q_low；统计区间是 [L,+∞)，
不是 [q_low,q_high]。先完成这一候选的诊断，再决定是否进入 basic/BCa 比较。
这不预先把 percentile 定为确认方法。SciPy 区分配对抽样、单侧形式和各区间方法，
并说明 BCa 的退化情形，见[官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)。

## 真值已知的联合分布

所有列出的数值乘 s=2^-24；概率由整数权重精确给定。这里直接构造 D，
不宣称每个联合取值都对应某个可实现的 softmax 输入。

| 名称 | (separate, FMA) 取值 | 对应权重 | 真均值/s |
| --- | --- | --- | --- |
| symmetric_identical | (−1,−1), (1,1) | 1,1 | (0,0) |
| symmetric_corr08 | (−1,−1), (1,1), (−1,1), (1,−1) | 9,9,1,1 | (0,0) |
| rare_negative | (1,1), (−31,−31) | 31,1 | (0,0) |
| rare_positive | (−1,−1), (31,31) | 31,1 | (0,0) |
| zero_constant | (0,0) | 1 | (0,0) |
| positive_constant | (1,1) | 1 | (1,1) |
| mixed_null_positive | (−1,1), (1,3) | 1,1 | (0,2) |

第一格两 arm 完全相同，第二格相关系数恰为 4/5；混合格检查合取零假设，
避免只在“所有真均值恰好为零”的点检查误报。多分布层的四条件联合判据尚未实施，
这里的两 arm 合取只是局部诊断。常正格不是正式功效分析，不据此决定确认样本量。

## 单次实验评分：用户核心

`confirmation_calibration.assess_trial` 接收两个下界的数值区间与两个已知真均值。
对每个 arm 使用其区间下端点 L：

- 覆盖真值：L <= theta。
- 宣称均值为正（拒绝非正均值零假设）：L > 0。
- 误报：宣称均值为正，并且真实 theta <= 0。
- 两 arm 合取通过：两项均宣称为正；该合取误报：通过且至少一项真均值 <= 0。

覆盖失败和误报不同：theta=2、L=3 时区间漏掉真值，但“theta>0”本身没有说错。
L=theta 仍覆盖，L=0 不拒绝。评分核心用精确比较，不能取区间中点或上端点。
常数观测样本也必须计入全部外层试验；另报是否为常数样本，不能静默丢弃或改方法。
若未来方法返回非有限值，应记录 invalid 并保留外层总数，不以剩余有效结果夸大覆盖率。

## 执行阶段与保存要求

当前只验证合成总体、可复现联合抽样、已有函数的拼装和手算评分测试。
Monte Carlo runner 要等评分核心完成与审计后再接，不运行隐式 CLI 或导入时实验。

候选资源规划（尚未冻结执行配置）：n=32/128，B=1999，每格外层 R=1000；
先以独立命名空间做 R=20、B=199 的运行时间预检。预检不作覆盖结论。
R=1000 仍有外层 Monte Carlo 误差；报告误报计数/总数及二项不确定区间，
区间方法、容许偏差和方法筛选规则须在有解释意义的校准批次前固定。
增大 B 与增大 R 分别解决内层近似和外层误差估计，均不替代实际确认轮的族数 n。

未来 runner 至少保存：协议与预测快照、源码 hashes、总体取值/权重/真值、n/B/R/alpha、
各外层输入、独立输入/重采样 RNG 种子及算法、逐次下界外包与评分、常数样本标记、
失败记录、分格汇总。不同阶段采用不同种子命名空间，失败不覆盖既有 artifact。
所有方法比较共用外层样本；能共用内层 draws 时也共用，不把相关比较当独立试验。
任何后续方法调整和新增压力条件都另记版本，不把校准探索当成预先验证通过。
