# 确认轮统计：从均值到下界

本页是学习说明，不是冻结协议；范围与统计方法选择见
[确认轮草案](online_confirmation_draft_v1.md)。当前进度只维护在
[NEXT_SESSION](../../../NEXT_SESSION.md)。

## 已写出的计算

每个输入族含两种 FMA 设置下的 D=A_chain−A_balanced。`paired_mean` 求指定族索引的
两列平均区间，`bootstrap_means` 对多组索引重复这个过程。函数局部累加变量在每次
调用时初始化，不用对函数返回值“清零”。重复索引代表多次抽取，必须保留。

这些区间包住指定样本均值的数值，不是总体均值的统计置信区间。bootstrap 用现有样本
近似重复抽样的波动；抽取更多次不会增加真实独立输入族数。

## 下一块：先学分位数

一个候选方法是 percentile bootstrap：若使用单侧 95% 下置信界，取 bootstrap 均值
分布的 5% 分位数，统计区间的形式是 [L, +∞)。这是近似推断方法，覆盖率还须评估，
不是当前已经选定的确认方法。配对重采样与单侧形式见
[SciPy 官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)。

接下来要学的数值工具只负责取分位数，也可供其他区间方法使用，不内置显著性阈值。
约定输入 B 个数、p 在 [0,1] 内；排序后用从 0 开始的位置 h=(B−1)p，
若 h 不是整数，就在相邻两个位置之间线性插值。p 与运算端点都用 Fraction，
不先转 float。B=1 时所有 p 都返回唯一的数；空输入拒绝。

手算例子：排序后的五个数为 −2、0、4、6、12。

- p=1/4：h=1，分位数是 0。
- p=1/8：h=1/2，位于 −2 和 0 正中间，分位数是 −1。

这里的 1/4、1/8 是教学参数，不是正式确认的显著性水平。

## 输入本身是区间时

每次 bootstrap 均值只知道落在 [l_b,u_b] 内。分别排序全部下界、全部上界，再取
相同 p 的分位数，得到 [q_low,q_high]。分位数对每个输入坐标单调，所以这个区间
包住未知精确均值列表的分位数。不要按整个区间元组排序后，直接取某行的两个端点；
两列的排序可能不同。也不要只用中点代替数值外包。

若选定 percentile 下界方法，可用 q_low 保守处理端点数值不确定性；这只能保证
数值方向保守，不会自动修复 bootstrap 的统计覆盖偏差。B=1 或全部值相同在数值上
可取分位数，但不能因此断言统计证据充分。

## 下界的含义

样本平均 D 为正，只说明本批输入平均而言 chain 更差。若一个已经选定并验证的
单侧推断方法给出 L>0，才支持相应条件下 theta>0 的确认判据；L≤0 表示未通过该
判据，不等于证明 theta≤0。四条件合取检验与四个同时置信界要按草案区分。
