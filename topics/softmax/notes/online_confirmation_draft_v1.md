# Online 确认轮草案 v1（未冻结、未运行）

2026-09-06。用户选定首要问题：**在固定输入分布和较大块数下，chain 的平均相对误差高于 balanced。**
归因规律保留为次要分析。以下是 agent 提案，不是已完成的预注册。

## 问题与范围提案

- 固定 n=2048、每块 32 个相同 logit，块内计算精确。结论只对应这个 n，不能写成“所有大块数”。
- 保留 uniform spread=8、25 × separate/FMA 四个条件，各自定义
  theta = E[A_chain−A_balanced]。四格分别报告，不以混池均值替代。
- 建议确认命题为四个条件的 theta 均 > 0。零阈值只对应用户选择的“更高”这一方向命题，
  不代表差距具有生产价值。工程上最小有意义效应仍未指定，不能由 pilot 差距倒填。
- 归因指标及 R 对 D 的重建程度只作次要描述，不作为 primary 失败后的替代通过条件。
- 输入使用独立新种子；原 pilot、归因输入不再作为确认数据。每个 spread 独立抽族，
  一个族同时执行两种 schedule 和两种 FMA arm。

已有 pilot 的同族复核表明，chain 根在 57/64 个 family 上 separate/FMA 逐位相同，
两种 arm 的配对 D 在 39/64 个 family 上完全相同。因此两种 arm 是高度相关的重复测量，
不能按四个独立样本组理解。是否把两种 arm 都放入 primary，还要先由目标 CUDA 算术合同决定；
若硬件目标只对应其中一种，另一种更适合作为诊断条件。

spread=25、n=32 的探索格中，每种 arm 都是 4 个 chain 更准、4 个根输出平局。
这个符号翻转可保留为边界现象，但当前 primary 已固定在 n=2048，不把该薄弱小格另立为
确认命题。

## 抽样单位与统计接口（本轮先实现）

抽样单位是**一个完整输入族**。先在同族内得到两项 D：separate 与 FMA，然后把这两项
一起有放回重采样。不能将 chain/balanced 分开抽，也不能把同族的两种 FMA 当成独立样本。
两个 spread 分别重采样；bootstrap 重复数增加只降低计算本身的随机性，不增加真实样本量。

现有 rewrite 的 group bootstrap 可作为概念参照，历史实现与冻结 RNG 边界原样保留。
本阶段新增用户统计核心：给定族索引求两 arm 的平均区间，以及按共同索引生成 bootstrap
均值分布。索引生成与输入检查由 agent 提供，核心由用户写。

为避免对大量超长 Fraction 分母重复求最小公倍数，统计输入先向外量化到 2^-128 网格。
下界向下、上界向上，单个端点扩张小于一个网格量子；统计输出仍保存分数区间。
这个网格不改变 primary 的定义，也不把数值外包区间称为统计 CI。
pilot 中 D 的实数参照区间远窄于该网格，因此进入统计模块后，数值外包宽度实际上由
2^-128 网格决定。它仍远小于观测效应，但输出应称为“网格外包的精确分数端点”，不能说
保留了原 real-exp 区间的全部分辨率。

## 置信区间提案（方法尚待验证）

建议先实现 bootstrap 均值分布，再比较 percentile 与 BCa 的适用性；不能因为旧代码
采用 percentile 就直接继承其覆盖率结论。SciPy 的公开实现区分 paired 重采样，以及
percentile/basic/BCa 三种区间，并提供不同单侧/双侧形式，见
[官方 bootstrap 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)。

这里必须先区分两个统计目标。若 primary 是单个合取命题“所有预先指定条件的 theta 均
大于 0”，对应 intersection-union test：每个分量以同一个 alpha 检验并要求全部通过，
不自动需要把 alpha 除以条件数。若目标是同时给出四个各自具有联合覆盖率的下置信界，
才需要 Bonferroni、max-T 或其他同时推断方法；Bonferroni 每格 0.0125 只是其中一个保守候选。
两种目标不能混写成同一条判据，且 FMA arm 的高度相关性要在方法校准中保留。

无论选哪一种，该统计覆盖都依赖 bootstrap 近似，数值区间严格并不保证统计覆盖严格。
需先确定并验证方法，记录重采样次数、插值定义、退化分布处理和 RNG。
在方法选择与样本量固定前，不发布可执行确认测量配置，也不抽新研究输入。

## 样本量与资源预算待定

每个 spread 的独立族数可先评估 32、64、128 三档；不是宣布其中任一档有足够功效。
应在选定统计方法后，用 pilot 的离散程度做保守的精度/功效规划，并记录小 pilot 的不确定性。
不允许看到确认区间后临时加样本，除非另行预先制定有效的序贯规则。
