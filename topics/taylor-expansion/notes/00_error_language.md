# 00 — Error Language and Orientation

状态：完成（2026-07-16）

## 目标

在进入具体余项公式前，固定 Taylor 研究中的对象和语言。

## 起点对象

在展开点 \(a\) 附近，定义 \(n\) 阶 Taylor polynomial：

\[
P_n(x)=\sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k.
\]

remainder 定义为精确差值：

\[
R_n(x)=f(x)-P_n(x).
\]

这一定义本身没有声称 \(R_n\) 很小。要得到“小”、阶数或数值上界，必须继续加入关于 \(f\)、区间和 \(x-a\) 的条件。

## 必须分开的四件事

1. **Actual error**：给定 \(f,a,n,x\) 后的真实 \(R_n(x)\)。
2. **Representation**：用导数、积分或某个中间点表达同一个 \(R_n(x)\)。
3. **Asymptotic order**：当 \(x\to a\) 时，误差相对于 \((x-a)^k\) 如何衰减。
4. **Bound**：在明确区间和假设下，保证 \(|R_n(x)|\) 不超过某个可计算量。

## 第一个检查问题

当我们写

\[
f(x)=P_n(x)+O((x-a)^{n+1}),
\]

这里给出的是局部 asymptotic upper order，并隐含一个局部存在的常数界。若常数和有效邻域没有显式给出，它还不是可直接使用的 numerical bound。

下一步用 \(R_2(x)=\sin x-x\) 比较 \(O(x^3)\)、\(O(x^2)\) 与 \(o(x^2)\)。

## 阶段结论

- \(R_n=f-P_n\) 是带符号的精确余项函数，absolute error 是 \(|R_n|\)；
- \(R=O(g)\) 表示 \(|R|/|g|\) 在目标极限附近有界；
- \(R=o(g)\) 表示 \(R/g\to0\)，即 \(R\) 相对 \(g\) 可忽略；
- 若 \(R=cg+o(g)\) 且 \(c\ne0\)，则 \(cg\) 是主导项；
- 对 \(R_2(x)=\sin x-x\)，有 \(R_2\sim-x^3/6\)，所以它是 \(O(x^3)\)、\(O(x^2)\) 和 \(o(x^2)\)，但不是 \(o(x^3)\)。
